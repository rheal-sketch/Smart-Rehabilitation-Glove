# Smart Rehabilitation Glove

A wearable rehabilitation glove designed to monitor hand and wrist movement and pressure during rehabilitation exercises. The system uses an ESP32 microcontroller, MPU6050 motion sensor, flex sensors, and force-sensitive resistors (FSRs) to collect real-time data on wrist orientation, finger movement, and applied pressure.

The prototype integrates the sensors directly into a wearable glove, demonstrating how low-cost electronics can be used to track hand function and provide quantitative feedback for rehabilitation and movement analysis.

# Key Features

* Tracks wrist and hand orientation using an MPU6050
* Measures finger bending using flex sensors
* Detects applied pressure using FSRs
* Processes sensor data using an ESP32
* Integrates the electronics into a functional wearable glove
* Designed as a prototype for rehabilitation and hand-movement monitoring
